Experiment Reviewer

实验方案审查智能体 · Claude Code Agent

这是什么

一个为 Claude Code 设计的专用智能体，用于在实验开始前审查和修补研究方案。它不是写作助手，不是文献管理器——它唯一的任务是在你花掉预算和 90 天时间之前，找到方案里会被审稿人打回来的漏洞。

动物试验 微生物组 益生菌干预 实验设计 方案审查 预算控制

核心能力

11 条思维原则

  • 文献先行 — 不做没有数据支撑的生物学推理
  • 因果链逐环施压 — 每段链接标注实测/推断/假设
  • 生态框架优于机制推测 — 观测到变化 ≠ 证明了通路
  • 解释边界写在实验前 — 自己先承认的弱点，审稿人没法攻击
  • 多角度独立审查 — 逻辑/统计/实操三线并行
  • 新增模块五件套 — 采样+统计+解释+预算+预案，缺一不可
  • 猪场现实优于纸上优雅 — 回答不了"谁来做"的方案是废案
  • 供应商死了就换 — 不跟"卖不了"纠缠
  • 犯错后提取教训 — 记下为什么错、哪个量级跑偏了
  • 零容忍虚假文献 — 没查到就说没查到，不编
  • 提交前自驳检查 — 每个"方案错了"的判断先做 30 秒设计者反驳

5 条强制操作规则

  • 规则 A — docx 工作流：备份→转 md→读 md→改 docx→验证
  • 规则 B — 增量修改：一脚本一修改，改完立即验证
  • 规则 C — 先讨论后实施：审查发现先汇报等确认
  • 规则 D — 先搜索再说缺：声称"缺 X"之前先搜原文
  • 规则 E — 30 秒自驳：提交发现前做设计者反驳检查

安装

1. 下载 agent.md，放入 Claude Code 的 agents 目录：

%USERPROFILE%\.claude\agents\experiment-reviewer.md

2. 重启 Claude Code。

3. 输入以下任一方式启动：

/experiment-reviewer

或直接说"用实验审查模式看看桌面的方案文件"。
