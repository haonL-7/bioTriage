FERRET: Framework to Evaluate Robustness in Regulatory Networks Using Heterogeneous Cell Types.

FERRET is a new benchmarking framework for single-cell gene regulatory network (GRN) inference methods that evaluates robustness by comparing network estimates from the same versus different cellular states, avoiding reliance on ground-truth networks or simulations. It provides a more biologically relevant way to assess GRN inference performance using real heterogeneous cell type data.
