FERRET: Framework to Evaluate Robustness in Regulatory Networks Using Heterogeneous Cell Types.

FERRET is a new benchmarking framework for single-cell gene regulatory network (GRN) inference methods that evaluates robustness using real heterogeneous cell types, rather than relying on simulated or small ground-truth networks. It is based on the principle that GRN estimates from the same cellular state should be more similar to each other than to estimates from different states, providing a more biologically relevant performance metric.
