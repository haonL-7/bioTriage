CDState Resolves Malignant Cell Heterogeneity from Bulk Tumor RNA Sequencing Data.

CDState is a new computational method that deconvolves bulk tumor RNA sequencing data into distinct malignant cell states, capturing intratumor transcriptional heterogeneity without requiring single-cell reference data. By using an unsupervised approach, it overcomes the reference-data limitation of existing supervised deconvolution tools, enabling scalable analysis of cell-state diversity across many cancer types. This allows researchers to study tumor heterogeneity from widely available bulk RNA-seq cohorts.

PRISM-GEP: Viewing single-cell expression through the lens of topic modeling.

PRISM-GEP applies topic modeling to single-cell RNA-seq data to recover gene-expression programs (co-regulated gene modules) without forcing each gene into a single program. This better reflects the many-to-many nature of gene regulation, where cells run multiple programs simultaneously and genes participate in several. The tool offers a new lens for decomposing single-cell expression into overlapping, interpretable programs.

Condition-Associated Pattern Extraction and Recovery From Multi-Condition Single-Cell RNA-seq Data With CAPER.

CAPER is a new matrix factorization framework for multi-condition single-cell RNA-seq data that explicitly separates shared biological states from condition-specific variation, rather than merely producing visual embeddings or over-correcting and losing signal. It directly outputs condition-associated expression patterns and can recover cell-type-specific responses, addressing a key limitation of existing statistical and machine-learning methods.
