CellMAGE: cell-type deconvolution for multi-parent population analysis of gene expression.

CellMAGE is a new computational method for estimating cell-type proportions from bulk RNA-seq data in multiparental populations (MPPs). Unlike existing deconvolution tools that treat samples as genetically anonymous, CellMAGE leverages the known genetic contribution of each parental strain to each progeny, weighting parental cell-type reference profiles accordingly. This approach requires no model training or minimum sample size and was validated across 12 prefrontal cortex cell types in 16 Diversity Outbred mice.
