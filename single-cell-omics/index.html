scStable: assessing scRNA-seq analysis stability under bulk-derived between-sample variation.

scStable is a new framework that assesses how stable scRNA-seq analysis results are when between-sample biological variation is present, which is hard to evaluate when studies profile only one or a few samples. It generates synthetic samples that keep the original cell-level heterogeneity while injecting variation learned from bulk RNA-seq data. In gastric cancer data with 21 matched single-cell and bulk profiles, scStable reproduced real between-sample variation better than existing approaches like ZINB-WaVE, subsampling, and Gaussian noise.
