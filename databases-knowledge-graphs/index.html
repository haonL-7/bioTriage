PDBe-KB Complexes: Enabling Functional Insight from Macromolecular Complexes in the PDB.

PDBe-KB Complexes is a new resource that groups equivalent macromolecular assemblies from the PDB into unified complex-level records, consolidating data on component identity, stoichiometry, symmetry, ligands, and PISA-derived assembly properties. This provides a consistent framework for gaining functional insight into macromolecular complexes.
