HIT-MAP is an end-to-end framework that combines endogenous epitope tagging, optimized wide-field immunofluorescence imaging, and affinity purification-mass spectrometry to map subcellular protein organization in a scalable, cost-effective way. PDBe-KB Complexes: Enabling Functional Insight from Macromolecular Complexes in the PDB.

PDBe-KB Complexes is a new resource that groups equivalent experimentally determined macromolecular assemblies from the PDB into unified complex-level records. Each record consolidates component identity, stoichiometry, symmetry, ligands, and PISA-derived assembly properties, and links related complexes through composition comparisons. This provides a consistent framework for gaining functional insight into macromolecular complexes.
