PDBe-KB Complexes: Enabling Functional Insight from Macromolecular Complexes in the PDB.

PDBe-KB Complexes is a new resource that groups equivalent experimentally determined macromolecular assemblies from the PDB into unified complex-level records, consolidating data on component identity, stoichiometry, symmetry, ligands, and PISA-derived properties. It also links related complexes by comparing their compositions, capturing subcomplex relationships. This provides a consistent framework for gaining functional insight into macromolecular complexes.
