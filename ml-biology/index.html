De novo Design of a Vanadium Haloperoxidase.

This preprint reports the de novo design of a vanadium-dependent haloperoxidase, an enzyme that catalyzes carbon-halogen bond formation using a vanadate cofactor. The key challenge is that vanadate is an anionic oxometalate requiring precise hydrogen-bonding and electrostatic interactions rather than the coordinate-covalent bonds typical for metal-binding proteins. The work demonstrates that computational protein design can create a functional halogenase, a class of enzymes previously difficult to engineer.

EZpred: Improving Deep Learning-Based Enzyme Function Prediction Using Unlabeled Sequence Homologs.

EZpred is a deep learning method that improves enzyme function prediction (EC number assignment) by incorporating features from unlabeled sequence homologs, analogous to how AlphaFold leverages homologous sequences for structure prediction. This addresses a gap where most function-prediction models ignore the rich evolutionary signal available in unlabeled homologs.
