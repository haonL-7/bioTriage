Protein sequence domain annotation using a language model.

PSALM is a new protein domain annotation method that combines a pretrained protein language model (ESM-2) with a per-residue domain-state classifier and a structured probabilistic decoder to produce non-overlapping domain calls with explicit boundaries and scores. Benchmarked on 76.9M sequences with 107M annotated domains, it improves domain-detection sensitivity over profile-HMM scanning. This offers a language-model-based alternative to the standard HMMER-style annotation pipeline.

Viro-BERT: Whole-genome attention for robust viral pathogen classification from next-generation sequencing data.

Viro-BERT addresses 'Truncation Blindness' in viral pathogen classification by processing complete genomes rather than just the first few hundred to few thousand base pairs. It splits genomes into overlapping 512-token windows, encodes each with a shared DistilBERT encoder, and aggregates window-level representations for whole-genome classification. This enables the model to use the >95% of sequence ignored by fixed-window classifiers, improving classification of large DNA viruses like monkeypox and HSV-1 from NGS data.

ToxiFusion: integrating contextual and compositional sequence representations for toxic peptide prediction.

ToxiFusion introduces a computational framework for predicting toxic peptides from sequence alone by combining contextual and compositional sequence representations, aiming to improve peptide safety assessment and therapeutic development. The authors also highlight that reported performance of existing predictors can be inflated by representation limitations and evaluation bias, motivating a more robust modeling approach.
